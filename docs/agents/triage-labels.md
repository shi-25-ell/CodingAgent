# Triage labels

工程 skills 使用五个固定的 triage role。下表定义这些 role 在本项目 issue tracker 中对应的实际 label。

| Skill 中的 role | GitHub label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交由 agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工判断或实现 |
| `wontfix` | `wontfix` | 已决定不处理 |

当 skill 提到某个 triage role 时，使用表中对应的 GitHub label。若以后调整项目的 label 命名，只修改右侧 `GitHub label` 列，避免创建语义重复的 labels。
